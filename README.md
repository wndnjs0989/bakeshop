# 프로젝트 소개 (전국빵집 정보현황)

전국 빵집 정보 현황을 분석하고, Elasticsearch와 Kibana를 활용해 시각화 대시보드로 구현한 개인 프로젝트입니다.

# 프로젝트 소개
R과 Elasticsearch, Kibana를 활용한 데이터 분석 및 시각화 개인 프로젝트입니다. 
데이터의 수집부터 분석, 그리고 대시보드를 통한 시각화까지 전 과정을 직접 구현하여 인사이트를 도출하는 것을 목표로 합니다.

# 개발 환경

- **Backend & Analytics:** R
- **Search & Monitoring:** Elasticsearch, Kibana
- **Tools & Environment:** GitHub

# 주요 기능

- **데이터 수집 및 전처리**
  - 대상 데이터 수집 및 정제
  - 분석 목적에 맞춘 데이터 가공 및 파이프라인 구축
- **데이터 분석 및 모델링 (R)**
  - R을 활용한 심층 통계 분석 및 인사이트 도출
  - 데이터 패턴 분석 및 시각화용 데이터셋 가공
- **검색 및 대시보드 시각화 (Elasticsearch & Kibana)**
  - Elasticsearch를 통한 데이터 색인 및 검색
  - Kibana를 활용한 실시간 대시보드 및 시각화 차트 구축
- **프로젝트 관리 및 문서화**
  - GitHub를 통한 소스 코드 및 버전 관리
  - 최종 발표 자료 제작 및 시연 준비
